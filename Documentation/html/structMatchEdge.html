Detailed Description

Estrutura interna que representa uma aresta de correspondencia submissao-revisor.

Guarda os indices e IDs necessarios para reconstruir a atribuicao apos correr o Max-Flow, juntamente com um ponteiro para a aresta de fluxo real no grafo.
